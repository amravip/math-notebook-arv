# AGENTS.md

## Quick facts
- Static site (plain HTML/CSS/JS), no frameworks, no backend, no npm deps. 
- 24 chapter pages in `topics/`, generated from `_source/original-single-page.html` via `tools/generate-book.mjs`. 
- `js/toc-data.js` and `js/toc-art.js` are generated (do **not** hand-edit). 
- 6 chapters (`graphs`, `angles`, `shapes`, `transformations`, `pythagoras`, `circles`) use dynamic client-side question generation (`js/quiz-engine.js`); the other 18 use static question banks baked into pages.
- Progress stored in `localStorage` only.

## Commands
```bash
npm test                # node --test tests/*.test.mjs (runs against real runtime files)
node tools/dev-server.mjs  # http://127.0.0.1:8000/
node tools/generate-book.mjs
node tools/validate-book.mjs
```
- After editing `_source/original-single-page.html` or lesson/enrichment/format helpers, regenerate: `generate-book.mjs` then `validate-book.mjs`.
- `validate-book.mjs` is the structural guard (single `<h1>`, no heading skips, no unknown HTML entities, lesson figures must stay inside viewBox with balanced SVG tags). It reads from generated `js/toc-data.js`/`js/toc-art.js` and checks all pages.

## Generation details (gotchas)
- `tools/generate-book.mjs` extracts `CURRICULUM`/`CH`/`ORDER` by `vm.runInContext` on a slice of `_source/original-single-page.html` (sandboxed). Data fixes live in `applyContentFixes()` (patches over loaded data), not by editing the archived source.
- Static topic answers get `accept[]` derived via `stripTags()` (handles `.frac` spans, avoids stripping `<` as tag when used as operator). Explicit `accept` arrays override.
- Dynamic topics get placeholders `#dyn-worked`, `#dyn-tabs`, `#dyn-panes`, `#dyn-assignment` and call `window.QuizEngine.renderDynamicTopic()`.
- All pages load `js/tile-builder.js` (harmless if no `.tile-builder` elements). Tile widgets prefer to write into the same input.
- Cover art per topic comes from `tools/topic-art.mjs`; card vars from `cardVars()`.

## Testing
- Tests use Node's built-in test runner against real runtime files (`tests/*.test.mjs`). 
- Key suites: `marking.test.mjs` (correct/wrong/format), `tile-spec*.test.mjs`, `format-hint*.test.mjs`, `quiz-tile-spec.test.mjs`, `explore-challenges.test.mjs`.
- `tests/helpers.mjs` provides shared helpers.

## Boundaries
- `js/toc-data.js`, `js/toc-art.js` generated. `topics/*.html`, `index.html`, `contents.html`, `about.html` generated by `generate-book.mjs`.
- Hand-maintained: `practice.html`, `progress.html`, `css/styles.css`, all files in `js/` (runtime), `tools/lesson-content.mjs`, `tools/enrichment-content.mjs`, `tools/format-hint.mjs`, `tools/tile-spec.mjs`, `tools/svg-kit.mjs`, `tools/topic-art.mjs`, etc.
- `tests/` validates runtime behavior/formatting; `validate-book.mjs` validates generated structure.
