A sequence is an ordered list following a rule. Spotting the rule predicts any term without listing them all — the doorway to algebra.

A sequence is an ordered list of numbers built by a rule. Each number is a term, and its position in the list is called n — so the 1st term has n = 1, the 100th has n = 100.

From a sequence to its rule

  • A term-to-term rule tells you how to get the next term from the one before — "add 4". It is easy to spot but useless for jumping ahead.
  • A position-to-term rule (the nth-term rule) goes straight to any term. For example, with 4n + 3, term 100 = 4 × 100 + 3 = 403, with no need to list terms 1–99.
  • Always test a rule you have found on a term you did not use to build it. For 7, 11, 15, 19… the rule 4n + 3 gives n = 2 → 11. ✓
  1. Find the common difference between consecutive terms. If it is not constant, the rule is not linear — go to second differences.
  2. Write that difference × n as the start of the rule.
  3. Compare at n = 1: whatever is missing (or extra) is the number you add or subtract.
  4. Check on another term. A rule that works for n = 1 only is a coincidence, not a rule.

When the gaps themselves change

  • Two families are worth knowing on sight: the square numbers 1, 4, 9, 16… with nth term n², and the triangular numbers 1, 3, 6, 10… with nth term n(n + 1) ÷ 2.
  • Constant second differences always mean the rule involves n². For example, 2, 6, 12, 20, 30 has second differences of 2, and its nth term is n(n + 1).

🎭 Theatre seating

Row 1 has 10 seats, and each row behind has 4 more: 10, 14, 18, 22… The nth-term rule is 4n + 6, so row 20 has 4×20+6 = 86 seats — no need to count every row in between.

💰 Loan repayments

A loan balance drops the same amount each month: $2000, $1800, $1600… The term-to-term rule (subtract 200) predicts next month, but the nth-term rule predicts any month instantly.

🏗️ A growing tiled border

A tiled border around a growing pool needs 8, 12, 16, 20… tiles. Spotting the nth-term rule 4n + 4 tells you exactly how many tiles any size pool needs, without building a model first.

Why a rule like 3n + 2? If a sequence rises by 3, its rule has 3n; the '+2' shifts every term to match the real first value. Always test on term 1.
